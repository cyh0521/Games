Lucky Spin｜幸運轉盤
=====================

版本：v26
用途：可直接部署於 GitHub Pages 的單頁抽獎轉盤。

【檔案內容】
- index.html：轉盤主程式與介面。
- options.json：預設備選項目資料。
- image.png：中央小象按鈕圖片。
- tick.wav：指針通過分隔線時播放的「噠」聲。
- README.txt：本說明文件。

【基本功能】
1. 支援 1～20 個備選項目。
2. 項目可直接在左側輸入框修改。
3. 可按「＋ 新增備選項目（最多20選項）」增加項目。
4. 每個項目右側的 × 可刪除該項目。
5. 可開啟「抽中後移除」，抽中的項目會在結果顯示後自動從本局移除。
6. 下方保留抽選紀錄。
7. 抽中時會顯示彩帶效果。
8. 最終結果顯示為「抽中 獎項名稱」，獎項名稱會以較大、彩色粗體顯示。

【蓄力轉盤操作】
中央小象就是轉盤的操作按鈕。

- 按住中央小象：開始蓄力。
- 小象外圍的環形進度會隨蓄力逐漸增加。
- 約 1.8 秒達到最大力道。
- 放開滑鼠或手指：立即開始旋轉。
- 輕點時約旋轉 3～4 圈，時間約 2.8 秒。
- 最大蓄力時約旋轉 12 圈，時間約 7 秒。
- 支援滑鼠、觸控，以及鍵盤 Space／Enter 操作。

蓄力只影響轉盤的旋轉圈數與轉動時間，不影響抽選機率。
程式會先以亂數公平決定抽中項目，再依照蓄力程度計算旋轉圈數與動畫時間，最後精準停在抽中的扇形。

【指針與音效】
- 指針位於轉盤左側中央。
- 每當扇形的白色分隔線通過指針時，指針會產生一次機械式撥動。
- 同一時間播放 tick.wav。
- 高速旋轉時會形成快速「噠噠噠」聲，減速後聲音間隔會自然拉長。
- tick.wav 使用多個預載 Audio 物件輪替播放，以降低高速旋轉時音效互相截斷的情況。
- 瀏覽器通常要求使用者先進行一次操作才能播放聲音，因此按下中央小象時會同步啟用音訊。

【隨機抽選】
抽選使用瀏覽器 crypto.getRandomValues() 產生亂數。
每個目前有效的備選項目具有相同的抽中機會。
蓄力時間、旋轉速度、指針位置與使用者放開按鈕的時機，都不會改變已隨機決定的結果。

【options.json】
網站載入時會讀取 options.json，格式如下：

{
  "items": [
    "選項一",
    "選項二",
    "選項三"
  ]
}

最多讀取 20 個項目。

使用者在網頁上修改、新增或刪除項目，只影響目前開啟的頁面，不會寫回 options.json。
重新整理頁面後，會重新載入 options.json 的內容。
讀取 options.json 時使用 no-store 與時間參數，以降低 GitHub Pages／瀏覽器快取舊資料的情況。

【GitHub Pages 部署】
請將以下檔案放在同一個網站資料夾：
- index.html
- options.json
- image.png
- tick.wav
- README.txt

請勿只更新 index.html 而漏掉 tick.wav 或 image.png，否則音效或中央圖片會無法正常載入。

若 GitHub Pages 更新後仍顯示舊版本，可先確認瀏覽器分頁標題是否為「Lucky Spin v26」，再進行強制重新整理或清除該網站快取。

【注意事項】
- 建議使用最新版 Chrome、Edge、Safari 或 Firefox。
- 若裝置處於靜音、瀏覽器分頁被靜音或系統音量過低，tick.wav 可能聽不到。
- GitHub Pages 必須以 HTTPS 正常載入所有檔案。
